Privacy policy

MacBook Server Backup

MacBook Server Backup is a private tool used by a single person to back up that person’s own server to that person’s own Google Drive account. It has no other users.

Data the tool handles

The tool reads files from the owner’s own server, encrypts them on that server, and uploads the encrypted result to the owner’s Google Drive. The encryption password never leaves the server and is held in a root-only file.

Third parties

No data is sent anywhere except Google Drive, and only for the purpose of storing the encrypted backup. The tool contains no analytics, telemetry, advertising or tracking, and it does not sell or share data with anyone.

Google account data

The tool uses the Google OAuth scope https://www.googleapis.com/auth/drive.file, which limits it to files it created itself. OAuth credentials are stored only on the owner’s server, readable only by its administrator, and are never published.

Retention and deletion

The tool keeps 30 daily and 12 monthly encrypted recovery points and deletes older ones. Deleting the MacBook-Server-Backups folder in Google Drive, or revoking the app’s access from the Google Account permissions page, removes the stored backup data.
