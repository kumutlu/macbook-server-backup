MacBook Server Backup

A personal backup tool for one person. It copies encrypted snapshots of its owner's own machine to that same person's own Google Drive account. It is not distributed, has no other users, and provides no service to the public.

What it can access

It requests exactly one Google permission, https://www.googleapis.com/auth/drive.file. With this permission the tool can only see and manage the files and folders that it creates itself in Google Drive. It cannot read, list, change or delete any other content in the account.
