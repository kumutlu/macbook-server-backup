MacBook Server Backup

A private, single-user backup tool.

This application is used by one person to copy encrypted, incremental snapshots of a home Ubuntu server to that same person’s own Google Drive account. It is not distributed, has no other users, and offers no service to the public.

What it can access

It requests exactly one Google permission, https://www.googleapis.com/auth/drive.file. With this scope the application can only see and manage the files and folders that it creates itself inside Google Drive. It cannot read, list, modify or delete any other content in the account, and it shares nothing with anyone.

How it runs

The tool runs once a night on the server as a system service, uploads only the parts of the snapshot that changed, verifies the result, and keeps 30 daily and 12 monthly recovery points. Every file is encrypted on the server before it is uploaded.
